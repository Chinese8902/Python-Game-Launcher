# Python-Game-Launcher
安卓Python游戏终端运行器

## 项目说明
本项目为Android终端外壳程序，内置Python游戏运行环境，基于现有安卓Python终端进行学习向改造，删减冗余功能、移除内置广告，全部游戏逻辑代码封装于APK内部，不对外开源。仅对外发布成品APK安装包。
